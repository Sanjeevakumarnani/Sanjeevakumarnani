## Profile

I am a Computer Science & Engineering student focused on building and shipping software rather than only studying frameworks.

My work spans full-stack web applications, AI-assisted systems, Android applications, APIs, databases, deployment, and hackathon prototypes.

I care about three things:

- **Useful products** — software should solve a concrete problem.
- **Strong engineering** — clear architecture, typed code, testing, documentation, and maintainability.
- **Responsible AI** — provenance, human review, explicit limitations, and no false claims of autonomy.

## Engineering Principles

**Build first. Validate early. Document clearly.**

I prefer systems that:

- expose their architecture clearly
- distinguish real data from synthetic/demo data
- preserve source and provenance where it matters
- keep humans responsible for consequential decisions
- include reproducible setup and validation steps
- turn prototypes into maintainable projects
